# Formato para el body de GitHub Releases

## Formato recomendado

Interfaz: Nueva interfaz y nuevas funciones
Rendimiento: Mejoras de rendimiento y velocidad
Seguridad: Protección avanzada contra vulnerabilidades
Correcciones: Errores solucionados en el módulo de ventas

## Variaciones que también funcionan

### Con guiones

Interfaz - Nueva interfaz y nuevas funciones
Rendimiento - Mejoras de rendimiento y velocidad
Seguridad - Protección avanzada
Correcciones - Errores solucionados

### Con contenido en múltiples líneas

Interfaz:
Nueva interfaz y nuevas funciones

Rendimiento:
Mejoras de rendimiento y velocidad
La app ahora es un 40% más rápida

Seguridad:
Protección avanzada


## Palabras clave que la app reconoce

| Categoría | Palabras clave |
|-----------|----------------|
| **Interfaz** | `Interfaz`, `UI`, `Diseño`, `Design`, `Moderno` |
| **Rendimiento** | `Rendimiento`, `Velocidad`, `Rápido`, `Performance`, `Speed` |
| **Seguridad** | `Seguridad`, `Security`, `Protección`, `Protection`, `Safe` |
| **Correcciones** | `Correcciones`, `Errores`, `Bugs`, `Fixes`, `Solucionado` |
